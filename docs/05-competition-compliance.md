- [ ] 仓库公开可访问，无登录墙。
- [ ] 原理图、PCB、Gerber、BOM 齐全。
- [ ] 固件可编译/可运行，烧录与配置说明完整。
- [ ] 复现步骤、物料清单、接口定义完整。
- [ ] LICENSE 与 LICENSES/ 齐全，README 说明授权范围。
- [ ] 第三方代码、模型、库、参考设计的许可证已记录。
- [ ] 真实车牌、个人信息、密钥、WiFi 密码未提交。
- [ ] 演示视频与照片中的车牌已打码。

| 名称 | 用途 | 许可证 | 状态 | 备注 |

## 6. 风险与备注

1. 大赛规则可能更新，提交前必须重新核对官方页面；本清单不能替代官方规则。
2. “首发开源”意味着仓库应在提交前公开，且不包含未授权的第三方资料。
3. 打样券的使用门槛、抵扣范围、订单流程以大赛页面为准；不要先下单后补规则。
4. 演示视频中的车牌、门岗位置、人脸必须处理；避免泄露个人信息。
5. 若使用华秋版 KiCad，导出前检查版本兼容与 DFM 规则；若使用官方 KiCad，确保 Gerber 层名与华秋 CAM 兼容。
6. 参赛作品不得复制官方参考设计；RDK X5 底板参考设计只作为接口与电源设计依据，最终原理图与 PCB 为自研。
