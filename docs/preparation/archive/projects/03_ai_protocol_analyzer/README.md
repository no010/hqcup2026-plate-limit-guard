# 方案 03：AI 协议分析仪

## 概述

便携式智能总线分析工具，自动识别通信协议、检测异常帧，带彩色图形界面。

## 硬件架构

```text
[DUT UART] ──┐
[DUT SPI]  ──┼→ [信号调理/隔离] → [ART-Pi II] → [LCD屏] + [SD卡日志]
[DUT I2C]  ──┤      │
[DUT CAN]  ──┘   [逻辑采样]
                        │
                   [AI协议识别]
                   [异常检测]
```text
## 核心功能

- [ ] 4 路通道同时监听（UART/SPI/I2C/CAN 可配置）
- [ ] 自动波特率检测 / 协议识别
- [ ] AI 辅助异常检测（时序违规、CRC 错误模式、帧间隔异常）
- [ ] 彩色波形显示 + 协议解析树
- [ ] 数据导出（CSV / 逻辑分析仪格式兼容）
- [ ] 离线分析模式（回放 SD 卡中的捕获数据）

## 应用场景

1. **嵌入式调试**："这路 SPI 为什么偶尔丢数据？" → AI 提示"CS 建立时间不足"
2. **汽车电子**：CAN 总线异常帧自动标红，提示可能的故障节点
3. **产线测试**：批量验证设备通信协议合规性

## 技术栈

- RT-Thread + LVGL 图形界面
- STM32H7R 600MHz 主控 + NeoChrom GPU 加速 UI
- 轻量序列模型（LSTM / TCN）用于异常检测
- 协议解析引擎（类似 Wireshark 的嵌入式版）

## 评估检查清单

- [ ] 最高支持波特率/波特率（UART ≥ 1Mbps，CAN ≥ 1Mbps）
- [ ] 4 路同时采样不丢数据
- [ ] 协议识别准确率 > 95%（常见协议）
- [ ] 液晶 UI 帧率 ≥ 30fps
