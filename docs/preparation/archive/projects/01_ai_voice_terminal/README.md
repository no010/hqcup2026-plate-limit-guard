# 方案 01：低功耗 AI 语音交互终端

## 概述

基于 Edgi Talk 核心板的离线语音交互设备，无需云端即可实现唤醒、识别、反馈。

## 硬件架构

```text
[麦克风阵列] ──→ [Edgi Talk 核心板]
                       │
                       ├── Cortex-M55: 音频预处理、系统控制
                       ├── Ethos-U55: 关键词识别(KWS)模型推理
                       └── Cortex-M33: 低功耗待机、GPIO控制
                       │
[功放+扬声器] ←── [离线TTS输出]
[扩展按键/旋钮] ←── GPIO
[OLED显示屏] ←── SPI/I2C
```text
## 核心功能

- [ ] 离线语音唤醒（"你好小秋" 等自定义唤醒词）
- [ ] 离线命令识别（10-50 条固定指令）
- [ ] 离线 TTS 播报反馈
- [ ] 低功耗模式（语音唤醒后全速运行，平时休眠）
- [ ] 扩展板：麦克风阵列（2-4 路）、D 类功放、锂电池管理

## 应用场景

1. **智能家居中控**：语音控制灯光、空调、窗帘
2. **工业报警器**：异常时语音播报故障信息，工人语音确认
3. **老人/儿童陪伴**：离线故事机、语音提醒吃药

## 技术栈

- RT-Thread + Edgi Talk SDK
- TFLite Micro / Ethos-U55 工具链
- 关键词识别模型（MicroNet / DS-CNN）
- 轻量 TTS 模型（Piper / Chinese TTS 量化版）

## 评估检查清单

- [ ] Edgi Talk SDK 能否跑通官方语音 Demo
- [ ] NPU 推理延迟是否 < 200ms
- [ ] 离线 TTS 中文效果是否可接受
- [ ] 整机功耗能否 < 500mW（待机 < 50mW）
