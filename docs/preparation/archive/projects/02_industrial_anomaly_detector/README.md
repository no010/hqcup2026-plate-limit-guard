# 方案 02：边缘 AI 工业异常检测模块

## 概述

基于高性能 MCU 的边缘计算设备，实时采集多路传感器数据，本地运行轻量 AI 模型检测设备异常，无需上云。

## 硬件架构

```text
[加速度计] ──┐
[温度传感器] ─┼→ [ART-Pi II / FRDM-MCXA156] → [OLED屏] + [蜂鸣器/继电器]
[电流传感器] ─┤         │
[电压传感器] ─┘    [本地推理]
                        │
                   [异常时报警]
                   [可选：4G模块上报]
```text
## 核心功能

- [ ] 多路传感器同步采集（振动 1-4 轴 + 温度 + 电流）
- [ ] 信号预处理（滤波、FFT、特征提取）
- [ ] 轻量异常检测模型（AutoEncoder / Isolation Forest / 1-Class SVM）
- [ ] 实时阈值报警 + OLED 显示
- [ ] 数据日志存储（SD 卡 / Flash）
- [ ] 可选：ML307N 4G 模块异常上报

## 应用场景

1. **电机轴承监测**：振动频谱异常 → 预警轴承磨损
2. **机床刀具监测**：切削电流异常 → 预警刀具断裂
3. **电力配电柜**：温度+电流趋势异常 → 预警接触不良

## 技术栈

- RT-Thread / FreeRTOS
- CMSIS-DSP 信号处理库
- TFLite Micro / scikit-learn 嵌入式移植
- 传感器驱动（ADXL355、PT100、ACS712 等）

## 评估检查清单

- [ ] 传感器数据质量是否满足频谱分析要求
- [ ] 异常检测模型在 MCU 上推理时间 < 1s
- [ ] 正常/异常分类准确率 > 90%
- [ ] 连续运行 72 小时稳定性测试
