# 方案 04：AI 水面巡检终端 / 无人船

## 概述

小型化智能水面巡检平台，视觉识别 + 水质传感 + 远程通信。

## 硬件架构

```text
[摄像头] ──→ [RDK X5 / VisionFive 2] ──→ AI视觉识别
                                              │
[水质传感器] ──→ [FRDM-MCXA156] ──→ 数据采集     │
                                         │       │
[推进电机] ←── [SYS-F335D DSP] ←── 运动控制    │
                                         │       │
[4G模块 ML307N] ←── 远程通信/图传 ←──┘       │
                                              │
[地面站 RC3506] ←── 地图显示 + 遥控指令 ───┘
```text
## 核心功能

- [ ] 水面目标检测（漂浮垃圾、藻类、船只、落水者）
- [ ] 自动巡航与避障（基于视觉 + 超声波）
- [ ] 水质传感器采集（PH、浊度、溶解氧、温度）
- [ ] GPS 定位 + 电子围栏
- [ ] 4G 实时图传 + 数据回传
- [ ] 一键返航 / 低电量返航
- [ ] 地面站地图显示 + 遥控

## 应用场景

1. **城市河道巡检**：自动识别排污口、漂浮垃圾
2. **水产养殖**：夜间巡检死鱼、水质异常
3. **水域救援辅助**：快速搜索落水者并回传坐标

## 技术栈

- RDK X5 / VisionFive 2: YOLO / MobileNet 目标检测
- SYS-F335D: FOC 电机控制、舵机驱动
- ML307N: MQTT/HTTP 数据上传、远程指令
- 地面站: Web / Qt 地图界面

## 风险评估

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| 防水密封 | 🔴 高 | 采购现成防水船模壳体，不做自定义密封 |
| 重心稳定性 | 🟡 中 | 电池低位放置，先在水槽测试 |
| 多板通信 | 🟡 中 | 统一用 CAN/UART 组网，提前验证 |
| 开发周期 | 🔴 高 | 先做"漂浮球"简化版，再扩展为船 |

## 评估检查清单

- [ ] 目标检测 mAP > 0.7（至少 3 类目标）
- [ ] 通信延迟 < 2s（4G 环境下）
- [ ] 续航 > 30 分钟
- [ ] 水槽环境稳定运行 10 次无故障
