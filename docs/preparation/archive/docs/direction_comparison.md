# 候选方案深度对比

## 方案 01：低功耗 AI 语音交互终端 ⭐首选

**平台**：Edgi Talk（Cortex-M55 + Ethos-U55 NPU）

**核心功能**：

- 离线语音唤醒 + 命令识别（关键词 spotting）
- 离线 TTS（文本转语音）
- 无需云端，本地 NPU 推理
- 扩展板：麦克风阵列、功放、电源管理

**场景**：智能家居控制、工业报警提醒、无屏设备交互

**优势**：

- Edgi Talk 为此场景量身定制，硬件匹配度最高
- 离线 AI 语音是明确痛点（隐私、延迟、断网）
- 扩展板设计空间大，硬件分数有保障
- RT-Thread 生态支持完善

**风险**：

- 语音数据集准备耗时
- 离线 TTS 模型体积控制

**评分预估**：创新 25/30 | 实用 25/30 | 硬件 25/30 | 展示 18/20 | **总分 93**

---

## 方案 02：边缘 AI 工业异常检测

**平台**：ART-Pi II（STM32H7R）或 FRDM-MCXA156

**核心功能**：

- 振动/温度/电流传感器采集
- MCU 端轻量异常检测模型（AutoEncoder / 1-Class SVM）
- 实时预警，本地处理不上云
- OLED/LCD 显示 + 蜂鸣器/继电器报警

**场景**：电机轴承故障预警、机床刀具磨损检测、电力设备过热监测

**优势**：

- 工业预测性维护是真实市场需求
- 嵌入式 ML inference 在 MCU 上跑是技术亮点
- 完整闭环：采集→预处理→推理→报警→显示

**风险**：

- 需要真实工业数据或高精度仿真数据
- 异常样本少，模型训练有挑战

**评分预估**：创新 22/30 | 实用 28/30 | 硬件 23/30 | 展示 17/20 | **总分 90**

---

## 方案 03：AI 协议分析仪

**平台**：ART-Pi II（STM32H7R 600MHz + GPU）

**核心功能**：

- 多通道同时监听 UART/SPI/I2C/CAN
- 本地轻量模型自动识别协议类型
- AI 检测异常帧、时序违规
- GPU 驱动彩色 UI 展示波形和诊断结果

**场景**：嵌入式开发调试、汽车电子排故、工业总线维护

**优势**：

- 复用现有 dp-can + elaphureLink 经验，技术风险最低
- 创客工具方向，评委有认同感
- 协议分析是开发者真实痛点

**风险**：

- 多协议并行采集对时序要求高
- UI 交互设计工作量大

**评分预估**：创新 24/30 | 实用 26/30 | 硬件 20/30 | 展示 19/20 | **总分 89**

## 方案 04：无人船 / 水面巡检终端

**平台**：RDK X5（AI）+ SYS-F335D（电机控制）+ ML307N（4G）

**核心功能**：

- 视觉识别水面漂浮物/藻类/落水者
- 自动巡航 + 避障
- 水质传感器采集（PH/浊度/溶解氧）
- 4G 回传数据 + 远程遥控

**场景**：环保水质监测、智慧水产养殖、水域救援辅助

**优势**：

- 展示效果极强，视觉冲击力强
- 多开发板协同，技术覆盖全面
- 社会价值高（环保/救援）

**风险**：

- 需要船体、防水、推进系统（额外成本）
- 水环境调试复杂，密封/重心/进水风险
- 开发周期长，机械+硬件+软件并行

**评分预估**：创新 28/30 | 实用 24/30 | 硬件 22/30 | 展示 20/20 | **总分 94（高风险高回报）**
