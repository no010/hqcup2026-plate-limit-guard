# 结构与外壳

> 状态：待设计。当前没有 3D 模型或工程图。

## 设计目标

| 项目 | 目标 |
| --- | --- |
| 外形 | 约 150×110×50mm，壁挂或抱杆 |
| 防护 | 室内门岗 IP40；室外 IP54 |
| 材料 | 样机 3D 打印 PETG/ABS；量产 ABS 注塑或钣金 |
| 散热 | 侧面通风 + 防尘网；X5 散热片；风扇可选 |
| 安装 | 4×M3 螺钉；摄像头单独支架；天线外置 |
| 维护 | 免工具开盖或 4 颗螺钉；SD 卡、SIM 卡可触及 |

## 开孔与接口

- 摄像头视窗：避免反光，预留遮光罩。
- 扬声器格栅：4Ω 2.5–3W，开口率 ≥30%，防尘网。
- 状态灯导光柱：PWR/SYS/LTE/ERR。
- LTE 天线：金属外壳用 SMA 座；塑料外壳可用内置 FPC。
- 线缆：12V 电源、摄像头 USB、扬声器；建议防水格兰头。
- 隐私提示：外壳贴“仅识别车牌用于限行提醒，不保存车辆图像”。
